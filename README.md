## About

I started with the 42/1337 systems curriculum, reimplementing `libft`, `printf` and `get_next_line` from scratch, then building `minishell`, `cub3D` and `push_swap` to understand how software works underneath. That low-level foundation is still the base of everything I build.

These days I work mostly on AI integration, RAG systems and web backends with FastAPI, with Docker and Linux tooling underneath.
